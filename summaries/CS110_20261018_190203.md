# Summary: CS 110 Sequential Programming — Recitation 6

## Sequential Execution
Python executes code from top to bottom, one line at a time, in order. Nothing is skipped and nothing repeats automatically. This is what "sequential" means—the foundation of straight-line programming.

- Code runs exactly once in the order it appears.
- Understand the flow of your program by reading it line by line.
- Conditionals (if statements) come later; today focuses on sequential logic.

## Input and Type Casting
The `input()` function always returns text (a string), even when the user types numbers. To use that input in arithmetic, you must explicitly cast it to a numeric type.

- **Naming convention:** Read input into a variable ending in `Str`, then cast and store under the same name without `Str`.
  - Example: `agesStr = input("How old are you? ")` then `ages = int(agesStr)`
- **Why it matters:** `"5" + "3"` produces `"53"` (text concatenation), not `8` (addition).
- **Choosing the type:**
  - Use `int` for whole quantities you cannot divide: people, days, guests.
  - Use `float` for values that can have decimals: miles, gallons, degrees.

## Three Division Operators
Python provides three distinct operators for dividing numbers, each serving a different purpose.

- **True division (`/`):** Always returns a decimal. `7 / 2 → 3.5`
- **Floor division (`//`):** Returns only the whole part, discarding the remainder. `7 // 2 → 3`
- **Modulo (`%`):** Returns only the remainder. `7 % 2 → 1`
- **Combined use:** Together they split quantities. For 3725 seconds: `3725 // 3600 = 1 hour`, `3725 % 3600 = 125 seconds remaining`.

## Boolean Expressions and Values
A comparison is not a statement—it is a value that Python evaluates to `True` or `False`. You can store and print these values directly without an if statement.

- Example: `withinLimits = guests <= capacity` stores the result of the comparison.
- Example: `even = num % 2 == 0` stores whether a number is even.
- Print Boolean values as you would any other variable: `print("Within limits?", withinLimits)`

## Output Formatting
Making output readable requires spacing and rounding functions.

- `print("")` prints a blank line to space out output.
- `print("\n Title")` uses `\n` to skip a line before text.
- `print("\t Indented")` uses `\t` to insert a tab for indentation.
- `round(value, 2)` rounds to two decimal places.
- `round(value)` rounds to the nearest whole number.

## Math Module: Ceiling and Floor
The `math` module provides functions that always round in one direction, regardless of proximity to the nearest integer.

- **Ceiling (`math.ceil`):** Always rounds up. `math.ceil(4.2) → 5`
- **Floor (`math.floor`):** Always rounds down. `math.floor(4.9) → 4`
- **Import required:** Use `import math` at the top of your program.
- These functions are required for the assignment.

## Accumulation Pattern
Many programs need to build up a total by repeatedly adding to a variable. Initialize the total at zero, then add values one at a time.

- `total = 0` starts with zero.
- `total = total + num` adds `num` to the current value and stores it back in `total`. This is not an algebraic equation—it means "compute the right side, then store the result back into the variable."
- The same variable appears on both sides: this is how you update a value.

## Key Takeaways

- Python runs code sequentially from top to bottom; understand the flow by reading it in order.
- Always cast `input()` from string to `int` or `float` before arithmetic.
- Use the `Str` naming convention consistently: read into `nameStr`, then cast and reassign to `name`.
- Choose the right operator: `/` for decimals, `//` for whole parts, `%` for remainders.
- Store comparison results as Boolean values; print them directly without if statements.
- Format output with blank lines, tabs, and rounding functions for readability.
- Use `math.ceil()` to round up and `math.floor()` to round down.
- Practice accumulation by initializing a total and repeatedly updating it with `total = total + value`.
